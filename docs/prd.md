# 待办事项评分管理软件需求文档

## 1. 项目概述

### 1.1 产品愿景
开发一款智能待办事项管理软件，通过AI评分机制和积分激励系统，提升用户任务管理效率与完成动力，形成积极的任务完成闭环。\n
### 1.2 目标用户
- 个人生产力爱好者
- 学生群体
- 职场专业人士
- 需要任务激励的用户群体

## 2. 网站功能

### 2.1 用户管理模块
- 用户注册：邮箱验证，密码加密存储，注册表单图标为钥匙+用户轮廓
- 用户登录：邮箱+密码登录，记住登录状态，登录失败提示，门锁打开状态图标
- 忘记密码：邮箱重置，24小时有效期，重置后强制重新登录，钥匙+问号组合图标

### 2.2 待办事项核心功能
- 创建待办：标题、描述、截止时间、关联分组、优先级标签，自动AI评分，圆形加号渐变绿色添加按钮
- 评分标准管理：自定义评分标准JSON配置，预设模板，滑块+权重调整界面，天平+星星组合图标
- 待办列表视图：标题、倒计时、待办分数、完成状态，多种排序选项，颜色分级显示状态
- 待办编辑与删除：修改所有字段重新评分，二次确认删除，批量操作，铅笔（编辑）、垃圾桶（删除）图标

### 2.3 AI评分系统
- 评分流程：描述+用户标准→大模型API→解析评分→显示结果，脑图+星星组合图标
- 评分缓存机制：相同描述+标准使用缓存结果，评分失败显示默认分
- 评分展示：大号字体颜色渐变显示，点击查看详细评分依据

### 2.4 积分系统
- 积分规则：完成待办获得对应积分，提前完成奖励1.1倍，延期完成惩罚0.8倍，删除未完成任务无积分
- 积分显示：个人总积分导航栏显示，积分历史查看，积分趋势统计图，金币/奖杯图标

### 2.5 分组管理
- 分组功能：创建自定义分组、颜色标识、拖拽移动、分组统计，可折叠/展开分组侧边栏
- 视觉设计：颜色标签、文件夹+颜色标签图标

### 2.6 排行榜系统
- 排行榜类型：总积分榜、月榜、周榜，好友榜二期考虑
- 榜单展示：前10名显示，个人排名位置，奖牌标识，实时更新积分每日凌晨更新排名
- 视觉设计：领奖台背景图，用户头像+名称+积分，上升/下降趋势箭头，领奖台+皇冠图标

### 2.7 月度奖励邮件系统
- 奖励规则：每月最后一天23:59结算，可配置奖励名额，默认前三名不同奖励
- 邮件自定义：管理员后台配置，富文本编辑器，变量支持，附件支持虚拟奖杯图片
- 发送设置：每月1日上午9:00发送，重试机制，发送日志记录

## 3. 技术规格

### 3.1 性能要求
- 页面加载时间：<3秒
- AI评分响应：<5秒（有加载提示）\n- 并发用户支持：≥1000人同时在线

### 3.2 可用性要求
- 响应式设计：支持桌面端、平板、手机
- 无障碍访问：符合WCAG 2.1 AA标准
- 快捷键支持：常用操作键盘快捷键

### 3.3 安全要求
- 密码加密：bcrypt加密存储
- API安全：防刷分机制，API调用频率限制
- 数据隐私：用户数据不共享第三方

### 3.4 兼容性
- 浏览器支持：Chrome 90+、Firefox 88+、Safari 14+\n- 移动端：iOS 13+、Android 9+\n

## 5. 技术架构

### 5.1 技术栈
- 前端：Vue.js
- 后端：Python (FastAPI)\n- 数据库：sqlite3
- AI服务：OpenAI API
- 邮件服务：qqmail

### 5.2 数据模型关键表
```sql
-- 用户表
Users (id, email, username, password_hash, total_points, created_at)\n
-- 待办事项表
Todos (id, user_id, title, description, due_date, score, status, \n       group_id, created_at, completed_at)\n
-- 评分标准表
ScoringCriteria (id, user_id, criteria_json, is_default, created_at)\n
-- 分组表
Groups (id, user_id, name, color, order_index)\n
-- 积分历史表
PointsHistory (id, user_id, points, source_type, source_id, created_at)\n
-- 月排行榜快照
MonthlyRankings (id, year_month, user_id, rank, points, awarded_at)\n```
